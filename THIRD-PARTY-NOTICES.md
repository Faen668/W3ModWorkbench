## Decompiler research: tw3-cahirb by Aelto

Aelto's own `.rsblob` decompiler project helped fill gaps in this tool's decompiler: the complete, ordered list of the script engine's built-in operators, several rarely used instructions, the imported-property table, and a test blob from an older REDkit build. No code from tw3-cahirb is included; only facts about the file format were used, written up independently.

- Project: https://github.com/Aelto/tw3-cahirb
