## Anywhere

| Keys | Does |
|---|---|
| {{F1}} | this guide, at the page about the window you're in |
| {{Ctrl+O}} | open files |
| {{Ctrl+,}} | settings |
| {{Ctrl+Shift+A}} | the Asset Browser |
| {{Ctrl+Shift+E}} | Script Bench |
| {{Ctrl+Shift+B}} | build your mod |
| {{Ctrl+Shift+N}} / {{Ctrl+Shift+O}} | new project / open a project |
| {{Ctrl+Shift+G}} | search the game's strings |
| {{Ctrl+Shift+I}} | source inspector |
| {{Ctrl+Shift+L}} | load order analyser |

## In the main window

| Keys | Does |
|---|---|
| {{Ctrl+F}} | the search box |
| {{Esc}} | clear the search |
| {{Ctrl+E}} | extract the ticked files |
| {{Space}} | tick or untick the highlighted files |
| {{Enter}} | open the highlighted file |
| {{Alt+P}} | the preview pane on or off |
| {{Ctrl+A}} | highlight every file |
| {{Ctrl+C}} / {{Ctrl+Shift+C}} | copy the highlighted files' paths / names |
| {{Ctrl+D}} | compare the two highlighted files |
| {{Ctrl+Shift+D}} | other copies of the highlighted file |
| {{Shift+Alt+R}} | show in Explorer |

## In Script Bench and the text preview

| Keys | Does |
|---|---|
| {{Ctrl+S}} / {{Ctrl+Shift+S}} | save / save every changed file |
| {{Ctrl+Z}} / {{Ctrl+Y}} | undo / redo |
| {{Ctrl+F}} | search in the file; {{F3}} / {{Shift+F3}} next and previous match |
| {{Ctrl+Shift+F}} | [[Find in files]] (Script Bench) |
| {{Ctrl+Shift+W}} | [[Stub generator]], on the name at the cursor (Script Bench) |
| {{F7}} | compile (check) your scripts |
| {{Ctrl+Click}} or {{F12}} | go to definition |
| {{Ctrl+Alt+Click}} or {{Ctrl+F12}} | open the definition in the other group |
| {{Shift+F12}} | find all references |
| {{Ctrl+Shift+F12}} | who else changes this |
| {{Shift+Alt+H}} | type hierarchy |
| {{Ctrl+T}} | go to any class, function or value |
| {{Ctrl+Shift+O}} | the outline on or off |
| {{F2}} | rename (in a script) or rename the file (in the tree) |
| {{Ctrl+Space}} | suggest names |
| {{Ctrl+J}} | insert a snippet |
| {{Ctrl+.}} | refactor: extract, inline, split or join, lay out |
| {{Shift+Alt+F}} | format the script |
| hold {{Ctrl+Alt}} | show parameter names in calls |
| {{F4}} / {{Shift+F4}} | next / previous result in the list under the files |
| {{F8}} / {{Shift+F8}} | next / previous difference when comparing |
| {{Alt+Left}} / {{Alt+Right}} | back / forward |
| {{Ctrl+Tab}} / {{Ctrl+Shift+Tab}} | next / previous tab |
| {{Ctrl+W}} | close the tab |
| {{Ctrl+Shift+T}} | open the tab you closed last again |
| {{Ctrl+\}} | split or unsplit; {{Ctrl+1}} / {{Ctrl+2}} go to a group |

## In the 3D viewers

| Keys | Does |
|---|---|
| {{F}} or double-click | fit the model to the view |
| {{1}} / {{2}} / {{3}} | look from the front, side or top |
| {{T}} / {{W}} / {{G}} | textures, wireframe, the floor grid |
| {{I}} | the info panel |
| {{Space}} | play or pause an animation |
